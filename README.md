# Практическая работа №3 — Bootstrap 5 и JavaScript

## Цель
Адаптивная административная панель с компонентами Bootstrap 5 и пользовательскими обработчиками JavaScript.

## Данные
- `dataset/dashboard.json` — **четыре показателя** и **восемь операций** (вывод в карточки и таблицу).
- `dataset/notifications.json` — сообщения для блока уведомлений и всплывающего Toast.
- `dataset/assets/avatar.svg` и `chart.svg` — иллюстрации интерфейса.

## Технологии и компоненты
- Bootstrap 5.3.8 (CSS и `bootstrap.bundle.min.js`, подключение через CDN)
- Сетка `container-xl`, `row`, `col-*`, утилиты отступов
- `navbar` c `collapse`, карточки (`card`), адаптивная таблица (`table-responsive`), форма (`form-control`, `form-select`), `modal`, `offcanvas`, `toast`, `badge`, `alert`
- Собственные небольшие стили в `css/custom.css`
- JavaScript в `js/app.js`

## Как запустить с нуля
1. Клонировать репозиторий (`git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>`), открыть папку проекта в VS Code.
2. Запустить `index.html` через расширение **Live Server** (`Open with Live Server`). Другой вариант: в терминале из корня проекта выполнить `python -m http.server 5500` и открыть `http://localhost:5500/`.
3. Интернет нужен для получения Bootstrap CSS/JS с CDN. `npm install` не требуется.
4. Убедиться, что показываются четыре показателя, восемь операций и два уведомления.

Не запускайте `index.html` двойным щелчком как `file://`: браузер может заблокировать `fetch` исходных JSON.

## Сценарий проверки
1. На экранах шириной **375 px** и **1440 px** проверить navbar и отсутствие горизонтальной прокрутки.
2. Открыть «О проекте» — должен выдвинуться `offcanvas`.
3. Нажать «Показать уведомление» — появляется `Toast` на основе `notifications.json`.
4. Нажать «Добавить запись», отправить пустое/короткое название — поле получает `is-invalid` и выводится предупреждение.
5. Ввести минимум 3 символа и сохранить — новая запись появляется в таблице, Bootstrap `Modal` закрывается, появляется Toast.
6. Нажать «Только в работе» и обратно — фильтрация изменяет строки и счётчик.
7. Открыть DevTools → Console: не должно быть необработанных ошибок. В Network можно найти оба JSON и скрипты Bootstrap.
8. Для проверки обработанного сбоя временно переименовать `dataset/dashboard.json`, обновить страницу, убедиться в сообщении об ошибке и затем вернуть имя файла.

## Различие JavaScript
**Bootstrap JavaScript** выполняет поведение готовых компонентов: открывает/закрывает `navbar collapse`, `modal`, `offcanvas`, управляет `toast` и фокусом в диалогах. Кнопки используют `data-bs-toggle`/`data-bs-target`.

**Собственный `js/app.js`** загружает JSON через `fetch`, формирует DOM, создаёт новую запись, фильтрует таблицу, изменяет счётчик и проверяет поля формы. Программные вызовы `bootstrap.Toast.getOrCreateInstance(...).show()` и `bootstrap.Modal.getOrCreateInstance(...).hide()` связывают собственную логику с Bootstrap.

## Важные детали
- Все восемь исходных операций и четыре показателя взяты из `dashboard.json`, а сообщения — из `notifications.json`.
- Новые записи существуют только в оперативной памяти страницы. После перезагрузки возвращаются исходные восемь строк — это ожидаемо, серверное сохранение не требуется.
- Визуальные стили Bootstrap не копируются: `custom.css` отвечает только за фирменные цвета и небольшие декоративные изменения.
- Фильтрация и валидация работают на стороне браузера.

3. Проверялись пустое имя в форме и отсутствие исходного файла JSON.
4. При расширении выделили бы модули данных, компоненты и серверное API.
5. Проверка после клонирования — Live Server, доступность CDN, данные, клики, Console.
6. Семантическая разметка (`main`, `section`, `article`, `nav`) описывает смысл, CSS — внешний вид.
7. Браузерный JS — бизнес-логика и данные, Bootstrap JS — готовые интерактивные компоненты.
